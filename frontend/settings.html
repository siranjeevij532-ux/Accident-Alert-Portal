Settings

Set up where accident alerts go. Saved on this computer in the .env file - no restart needed.

1 · Email alerts

  1. Use a Gmail account as the sender. Turn on 2-Step Verification for it (Google Account → Security).
  2. Open myaccount.google.com/apppasswords, create an app password named "Accident portal" and copy the 16 letters.
  3. Paste the sender, the app password, and who should receive alerts (several addresses: separate with commas). Save, then press Send test email.

2 · Weather

  1. Create a free account at openweathermap.org.
  2. Open My API keys and copy the key. A brand-new key can take up to 2 hours to start working.
  3. Paste it here, save, then press Test weather.

3 · Nearest hospital and police station

No key needed - it uses free OpenStreetMap data and only needs internet. The distance is measured from the accident location you set on the Live monitor page. It searches 5 km, then 15 km, then 40 km.

4 · Webhook (optional)

A URL that receives a JSON message when an accident is confirmed (for example a Slack/Discord/Zapier hook, or your own server).
